## June 2026
{: #databases-for-mysql-gen2-jun2326}
{: release-note}

{{site.data.keyword.databases-for-mysql_full}} General Availability
:   {{site.data.keyword.databases-for-mysql_full}} is now generally available. This new generation offers enhanced performance, improved scalability, and better resource isolation compared to the previous generation.

Isolated Compute support
:   {{site.data.keyword.databases-for-mysql}} now supports Isolated Compute hosting model, providing dedicated CPU and RAM resources for your database instances. For more information, see [Hosting models](/docs/cloud-databases-gen2?topic=cloud-databases-gen2-hosting-models).

Enhanced monitoring and observability
:   Improved integration with {{site.data.keyword.monitoringfull}} and {{site.data.keyword.loganalysisfull}} for better visibility into your database performance and operations.

Simplified provisioning
:   Streamlined provisioning process with improved UI and API experiences. For more information, see [Provisioning](/docs/databases-for-mysql-gen2?topic=databases-for-mysql-gen2-provisioning).

Migration from Gen 1
:   Documentation and tools available to help migrate from {{site.data.keyword.databases-for-mysql}} Gen 1 to Gen 2. For more information, see [Migration guide](/docs/databases-for-mysql-gen2?topic=databases-for-mysql-gen2-howto-migration).
